Перенос данных типовой конфигурации 1С:"Бухгалтерия предприятия", редакции 3
в типовую конфигурацию 1С:"Розница", редакция 3.0./1С:"Управление нашей фирмой" редакция 3.0

=================================================================

В данном подкаталоге находятся файлы, которые необходимы для переноса данных:

Перенос данных БП 3 - Розница 3.0,УНФ 3.0.epf - внешняя обработка выгрузки данных
во внешний файл из конфигурации 1С:"Бухгалтерия предприятия", редакции 3 которая
использует для работы 1С:Предприятия 8.3, 8.5;

Для переноса данных необходимо выполнить следующую последовательность действий:

1. Выполните резервное копирование информационной базы конфигурации 1С:"Бухгалтерия 
предприятия", редакции 3. Проведите обновление конфигурации до указанной версии.

Важно! На момент переноса данных в информационной базе 1С:"Бухгалтерия предприятия",
редакция 3 не должно быть отрицательных остатков денежных средств, товаров по
складам и организациям. Информация об отрицательных остатках не будет выгружена
из информационной базы конфигурации. 

2. Выполните все регламентные процедуры в конфигурации 1С:"Бухгалтерия предприятия",
редакции 3. 

3. Откройте внешнюю обработку "Перенос данных БП 3 - Розница 3.0,УНФ 3.0.epf" 
с помощью пункта меню "Файл"-"Открыть". 
 
4. В появившемся диалоге укажите имя внешнего файла, в который будет
производиться выгрузка данных. Укажите дату, на которую актуальны остатки
товаров, денежных средств и взаиморасчетов.
 
5. В диалоговом окне появится список объектов, которые могут быть выгружены. По
умолчанию будет выгружена информация по настройкам основных параметров учета,
справочникам и остаткам, рекомендуемым к выгрузке. При необходимости можно
отключить выгрузку информации по любому из справочников или отключить выгрузку
остатков по любому из регистров конфигурации.
  
6. После настройки правил выгрузки данных необходимо нажать на кнопку
"Выгрузить". Данные будут выгружены во внешний файл.

7. Произведите установку конфигурации 1С:"Розница", редакция 3.0./1С:"Управление нашей фирмой" редакция 3.0.
 
8. Создайте новую информационную базу конфигурации 1С:"Розница", редакция 3.0./1С:"Управление нашей фирмой" редакция 3.0

9. В конфигурации 1С:"Розница", редакция 3.0./1С:"Управление нашей фирмой" редакция 3.0 сопоставьте предопределенную
организацию "Наша фирма" с соответствующей организацией конфигурации 1С:"Бухгалтерия 
предприятия". Для этого добейтесь соответствия реквизитов организации "ИНН" и
"Наименование" в обоих информационных базах.

10. Загрузите курсы валют и включите опции учета (несколько организаций, комиссионную торговлю и т.д.)

11. Для загрузки данных выберите раздел "Компания" - "Начальные остатки" 
- "Загрузка данных из БП 3". В открывшемся диалоговом окне укажите
внешний файл, в который была произведена выгрузка, и нажмите на кнопку
"Загрузить". Данные будут загружены в информационную базу из внешнего файла.
 
12. После проведения загрузки убедитесь, что данные загружены корректно. Остатки
товаров, денежных средств и взаиморасчетов фиксируются документом "Ввод
остатков". С помощью отчетов проверьте правильность выгрузки остатков в обеих
базах. 

Важно! Функционал предназначен для разового перехода, при повторных загрузках корректность данных не гарантируется.
