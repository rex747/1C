Перенос данных ГИИС ДМДК конфигурации Розница 8. Ювелирный магазин, редакция 2.3
в конфигурацию Розница 8. Ювелирный магазин, редакция 3.0.

=================================================================
Важно! Перенос выполняет только выгрузку данных партий: УИН, статусы, соответствие к номенклатуре/характеристике.

Для переноса данных необходимо выполнить следующую последовательность действий:

1. В конфигурации Розница 8. Ювелирный магазин, редакция 2.3 открыть сервис выгрузки номеров упаковок: Администрирование/Интеграция с ГИИС ДМДК/Выгрузить УИН/ИНП

2. В форме сервиса скорректировать параметры фильтра, если необходино.
- По организации - выгрузка данных партий по конкретной организации.
- Не выгружать выведенные из оборота - партии со статусом "Выведена из оборота" не будут выгружаться для уменьшения записей регистра.

3. Выполнить выгрузку.

4. В конфигурации Розница 8. Ювелирный магазин, редакция 3.0 выполнить полную настройку интеграции ГИИС ДМДК: Настройки/Интеграция с ГИИС ДМДК

5. Открыть сервис загрузки партий: Настройки/Интеграция с ГИИС ДМДК/Загрузить УИН/ИНП 

3. В сервисе выбрать файл и нажать "Далее"

4. Появится предварительная таблица данных загрузки в которой можно при необходимости скорректировать номенклатуру/характеристику.

5. Выполнить загрузку данных.
